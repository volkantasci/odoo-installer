## What is inside

The guides cover the **entire CLI surface**, from the first `oii doctor` on a fresh
machine to declarative fleet convergence:

- what the tool is and which problems it solves;
- how to install and upgrade it;
- the concepts that make it safe (`plan-first`, the tested-only whitelist, adopted
  stacks, ingress mode, …);
- a complete command reference with options, examples and expected output;
- configuration keys and every file the CLI touches;
- end-to-end workflow recipes;
- safety rules, exit codes, troubleshooting and FAQ.
